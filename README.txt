WONDER WORLD - games, stories and songs for kids, in 8 languages. Works without internet.

PHONES AND TABLETS (iPhone, iPad, Android phones and tablets, Chromebooks)
  Open the Wonder World web address once while online, then:
  - iPhone / iPad (Safari): tap Share, then "Add to Home Screen".
  - Android (Chrome): tap "Install app" (or menu > "Add to Home screen").
  - Then: Grown-ups > Settings > "Play without internet" > Download voices.
  After that it opens from the home screen with no internet, full screen, with touch.

COMPUTERS FROM THIS FOLDER (no internet needed)
  - Windows: double-click "Start Wonder World (Windows).bat" and keep its window open.
  - Mac / Linux: double-click "Start Wonder World (Mac, Linux).command" (Mac may ask to allow it in
    System Settings > Privacy & Security; Linux needs python3, which is usually installed).
  The game opens in your browser at http://localhost:8787. Chrome and Edge can also install it from there
  (the install icon in the address bar) so it opens like a normal app.

No ads, no tracking, no accounts. Everything your child does stays on the device.
